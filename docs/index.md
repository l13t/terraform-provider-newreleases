# newreleases Provider

The newreleases provider manages [newreleases.io](https://newreleases.io): which
projects are tracked, how their release notifications are delivered (email,
Slack, Telegram, Discord, Matrix, Microsoft Teams, Mattermost, Rocket.Chat,
Google Hangouts Chat, webhooks) and how they are tagged. Data sources expose
releases of tracked projects, which is useful for pinning versions elsewhere in
a configuration.

## Authentication

Create an API key on newreleases.io under **Settings → API keys**, then either
set `api_key` in the provider block or export it:

```shell
export NEWRELEASES_API_KEY="..."
```

## Example Usage

```terraform
# The API key is read from the NEWRELEASES_API_KEY environment variable
# when api_key is not set.
provider "newreleases" {}
```

## Rate limits

The API meters requests per hour: a `GET` costs 1 unit, every other method
costs 10. The provider retries responses with HTTP 429 (rate limited) and
HTTP 503 (maintenance) up to 3 times, honouring the `Retry-After` header and
otherwise backing off exponentially (capped at 60 seconds).
